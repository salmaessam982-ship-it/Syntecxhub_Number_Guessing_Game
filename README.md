# Number Guessing Game

A simple Python console game where the computer randomly selects a number and the player tries to guess it.

## Features

- Random number generation
- Higher/Lower hints
- Attempt counter
- Three difficulty levels
- Replay option
- Best score tracking
- Input validation

## Difficulty Levels

- Easy: 1 - 50
- Medium: 1 - 100
- Hard: 1 - 500

## Technologies Used

- Python
- Random Module
- Loops
- Conditional Statements
- Functions

## How to Run

1. Make sure Python is installed.
2. Clone the repository.
3. Open the project folder.
4. Run:

python number_guessing_game.py
